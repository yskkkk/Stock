# Berkshire Hathaway(BRK-B) 실적·밸류 정리

올랜드 캠 영상 기반 ([YouTube](https://www.youtube.com/watch?v=iAmQ7GUJQSQ&t=96s)) + 용어·해석 보충.

## 1. 실적 읽는 법 (용어)

| 영문 | 의미 | 해석 포인트 |
|------|------|-------------|
| **Revenue** | 매출 | 회사 전체 규모·성장 |
| **YoY** | 전년 동기 대비 증감률 | 성장 속도 |
| **Beat / Miss** | 컨센서스 대비 초과·미달 | EPS·매출 각각 따로 봄 |
| **QoQ** | 직전 분기 대비 | 계절성·단기 모멘텀 |

영상 요지: EPS·매출 모두 beat, YoY도 두 자릿수 성장 → “계속 beat 중”으로 읽음.

## 2. BRK 매출·이익 구조 (손익계산서)

버크셔는 **보험 + 투자 + 철도·에너지 + 제조·유통·서비스** 복합체.

### 보험·투자 쪽에서 자주 보는 항목

| 항목 | 쉬운 말 |
|------|---------|
| **Insurance premiums earned** | 받은 보험료 중, 해당 기간에 “서비스 제공분”으로 인식한 금액 |
| **Sales & services** | 보험·철도가 **아닌** 제조·유통·서비스 등 기타 사업 매출 |
| **Investment income** | 주식 배당 + 채권 이자 등 투자수익 |
| **Operating lease** | 보유 장비·자산을 빌려주고 받는 **임대수익** |

### 영업이익(Operating earnings)이란?

버크셔 맥락에서는 보통:

> **본업에서 나온 이익**  
> (보험 인수 + 투자수익 + 철도·에너지·제조 등)  
> ※ 주식 시세 차익(미실현 손익)은 빼는 경우가 많음 → “운영 실적”을 보려는 목적

영상 요지:

- 전체 영업이익 YoY **+16%** (보험은 부진, 제조·에너지·철도가 상쇄)
- 현금 → **자사주 매입 + 주식 순매수**로 쓰기 시작 (Abel 체제에서의 변화)

## 3. 가이던스·컨센서스 어디서 보나

| 용도 | 사이트 |
|------|--------|
| 컨센서스 EPS·매출, 히스토리컬 PER | [Seeking Alpha](https://seekingalpha.com) |
| 실적 캘린더·예상치 | Yahoo Finance, Finviz, Earnings Whispers |
| 회사 공식 실적·보도 | Berkshire IR / SEC 10-Q·8-K |
| 애널리스트 타깃·Fwd P/E | Yahoo Key Statistics, SA Estimates |

**가이던스**: 회사가 “올해 EPS ○○”라고 직접 말하는 것.  
버크셔는 전통적으로 **구체 가이던스가 거의 없음** → 실무에선 **애널리스트 컨센서스 EPS**로 대체하는 경우가 많음.

## 4. 자사주 매입 — 왜 “늘었는데도 악재”가 되나

- 규모가 **전보다 커도**, 시장이 미리 기대한 숫자보다 **작으면** 실망 매도 가능
- 해석 프레임:
  - **절대액** (실제로 샀나?)
  - **기대 대비** (서프라이즈인가?)
  - **현금 추이** (쓰는지 / 쌓기만 하는지)

영상 포인트: 2Q 자사주 **~$45억** — 역사적으로 크지만, **발표 전 기대치엔 못 미칠 수 있다**는 언급.

---

## 5. 기술적 분석 (보조만)

좋은 종목 전제하에:

1. **직전 저점 수평선** — 지지·분할매수 기준
2. **그 시점의 PER** 확인 (예: 저점 부근 ~22배)
3. **200일 이동평균** 이탈·저점 형성 시 → **분할매수** (한 번에 올인 X)

차트만으로 사지 않고, **밸류(저평가) + 차트(타이밍)** 를 같이 봄.

## 6. 간이 적정주가 (영상 방법)

### 공식

```
적정주가 ≈ 익년도(또는 2027) 컨센서스 EPS × 5년 평균 PER
```

### BRK-B 예시 (영상 수치)

| 항목 | 값 |
|------|-----|
| 2027 컨센서스 EPS | **21.57** |
| 현재 Forward PER | ~**24~25** |
| BRK-B **5년 평균 PER** | **22.46** |
| 판단 | 현재 배수 > 5년 평균 → **소폭 고평가** |
| 적정가 | **21.57 × 22.46 ≈ $484** |

### 매매 룰 (영상 스타일)

- 주가 **적정가 아래** → 저평가 구간으로 보고 분할매수 후보
- 위 → 고평가·추격 자제
- Seeking Alpha 등에서 EPS·히스토리컬 배수 확인

### 같은 방식 예시 (영상)

| 종목 | 대략적 적정가 논리 |
|------|-------------------|
| AAPL | 2027 EPS × 5년 평균(~30배) |
| GOOGL | 2027 EPS × ~23배 |
| BAC | 금융주 낮은 배수(~11배) |
| 보험주(예: Chubb) | ~12~13배 |

**한계**: 단순 PER 배수법. 금리·사이클·일회성 EPS·회계 왜곡은 반영 안 됨. “대략의 싸/비싸 지도”로 쓰는 게 맞음.

## 7. 투자 철학 (영상 핵심)

1. **이름 있는 우량주**의 밸류 + 분할매수 (생소한 잡주 X)
2. **인내** — 수익 실현까지 수개월(예: ~3~5개월) 버팀. 사팔금지
3. **포트 분산** — 성장주(나스닥·빅테크)만 몰빵하지 말고, 보험·금융 등 **방어주** 비중
   - 예: 나스닥 조정기에도 보험주가 올라가며 포트 완충

## 8. 용어 정리

### Forward PER (선행 PER)

```
Forward P/E = 현재 주가 ÷ 향후 12개월(또는 익년) 예상 EPS
```

- **Trailing PER**: 이미 난 실적 기준 (과거)
- **Forward PER**: 앞으로 날 실적 기준 (기대 반영)
- 성장주는 Forward가 Trailing보다 낮게 나오는 경우가 많음

### “BRK-B 5년 평균”이란?

보통 **최근 5년간 해당 종목의 평균 PER(또는 평균 Forward PER)**  
→ “이 회사가 **평소에 받던 배수**”의 기준선  
→ 현재 Forward PER이 이보다 높으면 상대적으로 비쌈

## 9. Seeking Alpha Valuation 표 상세 (스크린샷: GOOGL)

Seeking Alpha **밸류에이션(Valuation)** 화면은 “지금 주가가 비싼가?”를 여러 배수로 보고, **동종 섹터**·**과거 5년**과 비교한다.  
(참고 화면: Alphabet / GOOGL Valuation 표)

### 9-1. 열(컬럼) 의미

| 열 | 의미 |
|----|------|
| **지표** | 어떤 배수/수익률인지 |
| **섹터 상대 등급** | 같은 섹터 대비 SA가 매긴 등급(A~F). 프리미엄이면 잠김 |
| **GOOGL** (종목 열) | **지금** Alphabet의 그 지표 값 |
| **섹터 중앙값** | 같은 섹터 회사들의 **중간값** (평균보다 이상치에 덜 흔들림) |
| **섹터 대비 차이%** | `(종목 − 섹터중앙값) / 섹터중앙값` → +면 섹터보다 비쌈(배수 기준). 배당은 해석 방향이 반대 |
| **GOOGL 5년 평균** | 과거 5년 동안 이 종목이 **평균적으로 받던 배수** ← 영상에서 말한 “5년 평균” |
| **5년 평균 대비 차이%** | 지금이 과거 평균보다 얼마나 높/낮은지 → **역사적 고평가/저평가** 감각 |

영상 방식의 핵심은 **「현재 Forward PER vs 5년 평균」**.

---

### 9-2. 행(지표)별 상세

#### PER — 주가 ÷ 주당순이익

**공식:** `주가 / EPS`

| 구분 | 의미 |
|------|------|
| **TTM** (Trailing Twelve Months) | 지난 12개월 **실제** 이익 기준 |
| **FWD** (Forward) | 앞으로 12개월(또는 애널 컨센서스) **예상** 이익 기준 |
| **GAAP** | 회계기준 그대로 (일회성·감가상각 등 포함) |
| **Non-GAAP** | 일회성·비현금 등을 조정해 **본업 이익**에 가깝게 |

- 배수가 **낮을수록** “같은 이익 대비 주가가 싸다”
- 성장주는 보통 **FWD PER &lt; TTM PER** (미래 이익이 더 크다고 가정)

**GOOGL 스크린샷 예시 (영상 논리와 직결)**

| 항목 | 값 |
|------|-----|
| P/E Non-GAAP (FWD) | **17.22** |
| 5년 평균 | **23.21** |
| 5년 평균 대비 | 약 **−25.82%** |

→ 과거에 받던 배수보다 싸게 거래 중으로 읽는 구간 (역사적 저평가 쪽).

---

#### PEG — PER을 성장률로 나눈 값

**공식:** `PER / 예상 EPS 성장률(%)`

- 성장이 빠른 회사는 PER이 높아도 PEG는 낮아질 수 있음
- 전통적으로 **~1 전후**를 “성장 대비 적정” 감각으로 봄 (절대 법칙은 아님)

**GOOGL 예시:** Non-GAAP FWD PEG **1.20** vs 5년 평균 **1.36** → 성장 대비로도 과거보다 살짝 저렴한 쪽.

---

#### EV 계열 — “기업가치” 기준 배수

**EV (Enterprise Value)** ≈ `시가총액 + 순부채(부채 − 현금)`  
주주뿐 아니라 **채권자까지 포함한 회사 전체 가격**.

| 지표 | 의미 | 언제 유용 |
|------|------|-----------|
| **EV/매출 (TTM·FWD)** | 매출 1달러당 기업가치 | 이익이 들쭉날쭉할 때, 성장 초기 |
| **EV/EBITDA** | 영업현금성 이익(이자·세금·감가 전) 대비 | 업종 비교, 인수 밸류 |
| **EV/EBIT** | 영업이익 대비 | 감가상각 구조가 비슷한 회사끼리 |

PER은 **주식만**, EV 배수는 **자본구조(현금·부채)** 차이까지 맞춤.

---

#### 주가/매출 (P/S)

**공식:** `시가총액 / 매출` (또는 주가 / 주당매출)

- 적자·이익 왜곡이 있을 때도 씀
- **GOOGL 예시:** TTM **9.62** vs 5년 평균 **6.86** (+40% 근처)  
  → **매출 대비로는 과거보다 비싸다**는 신호
- 동시에 FWD PER은 저렴할 수 있음 → 이익률·성장이 올라가서 PER은 낮아지고 P/S는 높아진 패턴도 흔함  
  → **한 지표만** 보지 말 것

---

#### PBR (Price / Book)

**공식:** `주가 / 주당순자산(장부가)`

- 자산·자본 비중이 큰 금융·제조에 더 의미
- 구글 같은 무형자산·브랜드 회사는 PBR만으로 “싸다/비싸다” 판단이 약함

---

#### 주가/현금흐름 (P/CF)

**공식:** `시가총액 / 영업현금흐름` 등

- 회계상 이익보다 **실제 들어온 현금** 기준
- 이익 조작·비현금비용이 많을 때 PER 보조로 씀

---

#### 배당 수익률

**공식:** `연간 배당금 / 주가`

- GOOGL **~0.24%**처럼 낮으면 “배당주로 산다”기보다 **성장·자사주**가 주된 주주환원
- 배수가 아니라 **높을수록** 배당 매력↑ (다른 배수와 해석 방향이 반대)

---

### 9-3. 영상 방식으로 이 표를 쓰는 순서

1. 쓸 줄: `P/E Non-GAAP (FWD)` (또는 팀에서 정한 GAAP FWD)
2. 비교: 종목 열 vs **5년 평균**
3. 판단:
   - 지금 배수 **&lt; 5년 평균** → 역사적으로 저평가 쪽
   - **&gt; 5년 평균** → 고평가 쪽
4. 적정가 스케치: `컨센서스 EPS × 5년 평균 PER`
5. 교차확인: P/S·EV/EBITDA가 반대로 비싸면 “이익만 싸 보이는지” 한 번 더
6. 섹터 열: “同行 대비”용. 영상 핵심은 **자기 역사(5Y)**

### 9-4. 한눈에 보는 칸 선택

| 보고 싶은 것 | 보는 칸 |
|--------------|---------|
| 지금 얼마나 비싸? | 종목 열의 FWD PER |
| 예전에 비해? | 5년 평균 + 차이% |
| 同行 대비? | 섹터 중앙값 + 차이% |
| 성장까지 감안? | PEG |
| 부채·현금 반영? | EV/EBITDA, EV/매출 |
| 이익이 애매할 때? | P/S, P/CF |

## 10. 한 장 체크리스트

1. 실적: Revenue / EPS beat·YoY
2. 구조: 영업이익이 **어디서** 났는지 (보험 vs 제조 vs 에너지)
3. 자본배치: 자사주·순매수 — **기대 대비**까지
4. 밸류: `컨센 EPS × 5년 평균 PER` → 적정가
5. 차트: 직전 저점·200평·그 시점 PER
6. 실행: 적정가 아래 + 빠질 때마다 **분할**, 길게 보유
7. 포트: 성장 + 방어 섞기
