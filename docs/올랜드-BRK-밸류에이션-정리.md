올랜드 캠 영상 기반 ([YouTube](https://www.youtube.com/watch?v=iAmQ7GUJQSQ&t=96s)) + 용어·해석 보충.

## 1. 실적 읽는 법 (용어)

| 영문 | 의미 | 해석 포인트 |
|------|------|-------------|
| **Revenue** | 매출 | 회사 전체 규모·성장 |
| **YoY** | 전년 동기 대비 증감률 | 성장 속도 |
| **Beat / Miss** | 컨센서스 대비 초과·미달 | EPS·매출 각각 따로 봄 |

영상 요지: EPS·매출 모두 beat, YoY도 두 자릿수 성장 → “계속 beat 중”으로 읽음.

## 2. BRK 매출·이익 구조 (손익계산서)

버크셔는 **보험 + 투자 + 철도·에너지 + 제조·유통·서비스** 복합체.

### 보험·투자 쪽에서 자주 보는 항목

| 항목 | 쉬운 말 |
|------|---------|
| **Insurance premiums earned** | 받은 보험료 중, 해당 기간에 “서비스 제공분”으로 인식한 금액 |
| **Sales & services** | 보험·철도가 **아닌** 제조·유통·서비스 등 기타 사업 매출 |
| **Investment income** | 주식 배당 + 채권 이자 등 투자수익 |
| **Operating lease** | 보유 장비·자산을 빌려주고 받는 **임대수익** |

### 영업이익(Operating earnings)이란?

버크셔 맥락에서는 보통:

> **본업에서 나온 이익**  
> (보험 인수 + 투자수익 + 철도·에너지·제조 등)  
> ※ 주식 시세 차익(미실현 손익)은 빼는 경우가 많음 → “운영 실적”을 보려는 목적

영상 요지:

- 전체 영업이익 YoY **+16%** (보험은 부진, 제조·에너지·철도가 상쇄)
- 현금 → **자사주 매입 + 주식 순매수**로 쓰기 시작 (Abel 체제에서의 변화)

## 4. 자사주 매입 — 왜 “늘었는데도 악재”가 되나

- 규모가 **전보다 커도**, 시장이 미리 기대한 숫자보다 **작으면** 실망 매도 가능
- 해석 프레임:
  - **절대액** (실제로 샀나?)
  - **기대 대비** (서프라이즈인가?)
  - **현금 추이** (쓰는지 / 쌓기만 하는지)

영상 포인트: 2Q 자사주 **~$45억** — 역사적으로 크지만, **발표 전 기대치엔 못 미칠 수 있다**는 언급.

## 5. 기술적 분석 (보조만)

좋은 종목 전제하에:

1. **직전 저점 수평선** — 지지·분할매수 기준
2. **그 시점의 PER** 확인 (예: 저점 부근 ~22배)
3. **200일 이동평균** 이탈·저점 형성 시 → **분할매수** (한 번에 올인 X)

차트만으로 사지 않고, **밸류(저평가) + 차트(타이밍)** 를 같이 봄.

## 6. 간이 적정주가 (영상 방법)

### 공식

```
적정주가 ≈ 익년도(또는 2027) 컨센서스 EPS × 5년 평균 PER
```

### BRK-B 예시 (영상 수치)

| 항목 | 값 |
|------|-----|
| 2027 컨센서스 EPS | **21.57** |
| 현재 Forward PER | ~**24~25** |
| BRK-B **5년 평균 PER** | **22.46** |
| 판단 | 현재 배수 > 5년 평균 → **소폭 고평가** |
| 적정가 | **21.57 × 22.46 ≈ $484** |

### 매매 룰 (영상 스타일)

- 주가 **적정가 아래** → 저평가 구간으로 보고 분할매수 후보
- 위 → 고평가·추격 자제
- Seeking Alpha 등에서 EPS·히스토리컬 배수 확인

### 같은 방식 예시 (영상)

| 종목 | 대략적 적정가 논리 |
|------|-------------------|
| AAPL | 2027 EPS × 5년 평균(~30배) |
| GOOGL | 2027 EPS × ~23배 |
| BAC | 금융주 낮은 배수(~11배) |
| 보험주(예: Chubb) | ~12~13배 |

**한계**: 단순 PER 배수법. 금리·사이클·일회성 EPS·회계 왜곡은 반영 안 됨. “대략의 싸/비싸 지도”로 쓰는 게 맞음.

## 7. 투자 철학 (영상 핵심)

1. **이름 있는 우량주**의 밸류 + 분할매수 (생소한 잡주 X)
2. **인내** — 수익 실현까지 수개월(예: ~3~5개월) 버팀. 사팔금지
3. **포트 분산** — 성장주(나스닥·빅테크)만 몰빵하지 말고, 보험·금융 등 **방어주** 비중
   - 예: 나스닥 조정기에도 보험주가 올라가며 포트 완충

## 8. 용어 정리

### Forward PER (선행 PER)

```
Forward P/E = 현재 주가 ÷ 향후 12개월(또는 익년) 예상 EPS
```

- **Trailing PER**: 이미 난 실적 기준 (과거)
- **Forward PER**: 앞으로 날 실적 기준 (기대 반영)
- 성장주는 Forward가 Trailing보다 낮게 나오는 경우가 많음

### “BRK-B 5년 평균”이란?

보통 **최근 5년간 해당 종목의 평균 PER(또는 평균 Forward PER)**  
→ “이 회사가 **평소에 받던 배수**”의 기준선  
→ 현재 Forward PER이 이보다 높으면 상대적으로 비쌈

## 9. Seeking Alpha Valuation 표 보는 법

| 열 | 의미 |
|----|------|
| **지표** | 어떤 배수/수익률인지 |
| **섹터 상대 등급** | 같은 섹터 대비 SA 등급 (A~F) |
| **종목 열 (예: GOOGL)** | **지금** 그 지표 값 |
| **섹터 중앙값** | 동종 섹터 중간값 |
| **섹터 대비 차이%** | 지금이 섹터보다 얼마나 높/낮은지 |
| **5년 평균** | 과거 5년 평균 배수 ← 영상 “5년 평균” |
| **5년 평균 대비 차이%** | 역사적 고평가/저평가 감각 |

### 주요 지표

| 지표 | 의미 |
|------|------|
| **P/E TTM / FWD** | 주가÷실적(과거 12개월 / 예상). GAAP·Non-GAAP 구분 |
| **PEG** | PER ÷ 성장률. 성장 대비 비싼지 |
| **EV/매출·EBITDA·EBIT** | 시총+순부채 기준 배수 (자본구조 반영) |
| **P/S** | 주가÷매출 |
| **P/B** | 주가÷순자산 |
| **P/CF** | 주가÷현금흐름 |
| **배당 수익률** | 연배당÷주가 (성장주는 보통 낮음) |

### 영상 방식으로 쓰는 순서

1. `P/E Non-GAAP (FWD)` (또는 정한 GAAP FWD)
2. 현재 값 vs **5년 평균**
3. 현재 &lt; 5년 평균 → 역사적 저평가 쪽 / 반대면 고평가 쪽
4. 적정가 ≈ `컨센서스 EPS × 5년 평균 PER`
5. P/S·EV 배수가 반대로 비싸면 교차확인
6. 섹터 열은 **同行 대비**, 영상 핵심은 **자기 역사(5Y)**

## 10. 한 장 체크리스트

1. 실적: Revenue / EPS beat·YoY
2. 구조: 영업이익이 **어디서** 났는지 (보험 vs 제조 vs 에너지)
3. 자본배치: 자사주·순매수 — **기대 대비**까지
4. 밸류: `컨센 EPS × 5년 평균 PER` → 적정가
5. 차트: 직전 저점·200평·그 시점 PER
6. 실행: 적정가 아래 + 빠질 때마다 **분할**, 길게 보유
7. 포트: 성장 + 방어 섞기
