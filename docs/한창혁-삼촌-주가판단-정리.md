## 0. 용어 총정리 (모르는 사람용 · 소괄호로 뜻 풀이)

이 문서에 나오는 말을 **쉬운 한국어**로 풀어 둔 사전입니다.  
형식: **용어** (한자·영어·약어가 있으면 병기) = 뜻. 필요하면 숫자 예시도 붙입니다.

### 0-1. 이 문서의 핵심 기호

| 용어 | 풀이 |
|------|------|
| **E** (Earnings의 E, 여기서는 「벌 돈」) | 회사가 **1년에 주주 몫으로 남기는 이익**. 보통 **당기순이익** 또는 **EPS**를 씀. |
| **m** (multiple의 m, 「배수」「멀티플」) | 그 이익에 **몇 배를 쳐줄지**. 시장이 주는 배수는 대개 **PER**. 내가 정하는 배수도 m. |
| **V** 또는 **적정가치** (fair value에 가까움) | E × m 으로 나온 「이 정도면 적정하다」는 **시가총액 또는 주가**. |
| **적정주가** | 주식 **1주** 기준으로 본 적정가치. 보통 **EPS × m**. |
| **기준가** | 보수적으로 잡은 적정주가(아래쪽). |
| **목표가** | 「여기까지 갈 수 있다」고 보는 위쪽 가격(낙관이 섞일 수 있음). |

**한 줄 예:** 이익(E) 10조 원 × 배수(m) 8배 = 적정 시총(V) 80조 원.

---

### 0-2. 돈·회사 규모를 말하는 말

| 용어 | 풀이 |
|------|------|
| **주가** (stock price) | 주식 **한 주**가 시장에서 거래되는 가격. 단위 보통 **원/주**. |
| **시가총액** (시총, Market Cap) | 회사 전체를 지금 시세로 사면 얼마인지. **주가 × 발행주식 수**. 「회사의 가격표」. |
| **억 원** | 1억 = 100,000,000원. |
| **조 원** | 1조 = 1,000,000,000,000원 = **1만 억 원**. 큰 회사 실적은 조 원으로 말하는 경우가 많음. |
| **원/주** | 주식 1주당 얼마(원). EPS·BPS·주가의 단위. |
| **배** | 배수. 「8배」= 8을 곱한다. PER 16.6배 = 이익의 16.6배만큼 가격이 붙어 있다. |
| **%** (퍼센트) | 100분율. 영업이익률 50% = 매출 100원 중 영업이익 50원. |

**단위 환산 예:** 10,000억 원 = 1조 원. IR 표가 「억 원」이면 ÷10,000 해서 조 원으로 맞춘 뒤 계산.

### 0-3. 재무제표·공시 관련

| 용어 | 풀이 |
|------|------|
| **재무제표** (financial statements) | 회사의 성적표·가계부. 대표적으로 손익계산서·재무상태표·현금흐름표. |
| **손익계산서** (Income Statement, 손익) | **얼마를 팔고, 얼마를 남겼는지**를 보여주는 표. 매출→영업이익→순이익 순. |
| **재무상태표** (Balance Sheet, 대차대조표) | **지금 보유한 것(자산)**, **빚(부채)**, **주주 몫(자본)**을 찍은 표. |
| **현금흐름표** (Cash Flow Statement) | 실제로 **돈이 들어오고 나간** 흐름. 「이익」과 「통장에 남은 현금」이 다를 수 있어서 봄. |
| **연결** (연결재무제표, consolidated) | 모회사+자회사를 **한 덩어리**로 합산한 실적. 큰 상장사는 보통 **연결**을 봄. |
| **별도** (별도재무제표) | 모회사 **혼자**만의 실적. 연결과 숫자가 다름. |
| **공시** | 회사가 법적으로 공개하는 실적·사실. |
| **DART** | 한국 전자공시시스템. 재무제표·실적 발표문을 찾아보는 곳. |
| **IR** (Investor Relations, 기업설명) | 회사가 투자자에게 실적·전망을 설명하는 자료·활동. 「IR 자료」= 회사가 낸 설명 자료. |
| **결산** | 회계 기간을 마감해 **확정 실적**을 낸 것. 「2025년 결산」= 2025년 확정 숫자. |
| **분기** (Q1, Q2…) | 3개월 단위 실적. 1년=4분기. |
| **TTM** (Trailing Twelve Months) | **최근 연속 12개월**을 합친 실적. 「작년 달력」이 아니라 「지금으로부터 뒤로 12개월」. |
| **trailing** (트레일링) | **이미 나온** 과거 실적 기준. E_trailing = 이미 찍힌 이익. |
| **forward** (포워드) | **앞으로** 예상되는 실적 기준. E_forward = 내년(또는 향후 12개월) 예상 이익. |
| **가이던스** (guidance) | 회사가 「앞으로 이 정도 될 것 같다」고 **직접 제시한 전망 숫자**. |
| **컨센서스** (consensus, 줄여서 컨센) | 여러 **증권사 애널리스트 전망의 평균(또는 합의치)**. |
| **애널리스트** (analyst, 줄여서 애널) | 증권사 등에서 기업을 분석·전망하는 사람. |
| **상한** | 「이 이상으로는 잘 안 쳐준다」는 **천장** 숫자. |

### 0-4. 손익계산서 항목 (위에서 아래로)

| 용어 | 풀이 |
|------|------|
| **매출** (매출액, Revenue, Sales) | 물건을 팔아 **들어온 판매 대금**(비용 빼기 전). 「판 돈」. |
| **매출원가** | 그 물건을 만드는·사 오는 데 든 비용. |
| **판관비** (판매비와 관리비) | 광고·인건비·임대료처럼 영업에 쓰는 비용. |
| **영업이익** (Operating Profit, OP) | 매출에서 본업 비용을 뺀 **본업으로 남긴 이익**. 이자·세금 전인 경우가 기본 개념. |
| **영업이익률** | 영업이익 ÷ 매출 × 100(%). 「판 돈 100원 중 본업으로 몇 원」. |
| **당기순이익** (Net Income, 순이익) | 이자·세금 등까지 반영한 뒤 **최종으로 남은 이익**. |
| **순이익률** | 순이익 ÷ 매출 × 100(%). |
| **지배주주** (owners of the parent) | 그 회사의 **주요 주주 쪽 몫**. 자회사에 다른 주인(비지배지분)이 있으면 순이익을 나눔. |
| **지배주주 당기순이익** | 최종 이익 중 **우리 회사 주주에게 돌아가는 몫**. E로 쓰기 **가장 무난**. |
| **비지배지분** | 자회사의 **다른 주주** 몫. |
| **일회성 이익** | 부동산 매각처럼 **반복되기 어려운** 이익. E에서 빼는 편이 안전. |
| **EPS** (Earnings Per Share, 주당순이익) | **주식 1주당** 순이익. 단위 원/주. E를 주당으로 본 것. |
| **기본 EPS / 희석 EPS** | 희석은 전환사채 등으로 주식 수가 늘어날 가능성까지 나눈 EPS(더 보수적). |

**흐름 예:** 매출 100 → (비용) → 영업이익 40 → (이자·세금 등) → 순이익 30 → 주주로 EPS 계산.

### 0-5. 재무상태표·건전성

| 용어 | 풀이 |
|------|------|
| **자산** | 회사가 가진 것(현금·공장·재고 등). |
| **부채** | 갚아야 할 것(차입금·미지급금 등). |
| **자본** (자기자본, Equity) | 자산 − 부채. **주주의 몫(장부 기준)**. |
| **지배주주 자본** | 연결 기준에서 **우리 주주 몫 자본**. |
| **BPS** (Book-value Per Share, 주당순자산) | 자본을 주식 수로 나눈 값. **1주당 장부가치**. 단위 원/주. |
| **장부** (book) | 회계장부에 적힌 숫자. 「시장 가격」과 다를 수 있음. |
| **ROE** (Return On Equity, 자기자본이익률) | 순이익 ÷ 자본. 「주주 자본 100으로 **몇을 벌어 줬나**」(%). |
| **부채비율** | 보통 부채 ÷ 자본 × 100(%). **빚이 자본 대비 얼마나 많은지**. 낮을수록 빚 부담이 작은 편. |
| **유동비율** | 유동자산 ÷ 유동부채. **단기 빚을 갚을 힘이 있는지**. 100% 넘으면 단기적으로 여유 있다고 보는 경우가 많음. |
| **이자보상비율** (이자보상배율) | 영업이익이 이자 비용의 몇 배인지. **이자 낼 여력**. 높을수록 여유. |
| **유동자산 / 유동부채** | 1년 안에 현금화·상환되는 자산/부채. |

### 0-6. 가격·배수(밸류에이션) 지표

| 용어 | 풀이 |
|------|------|
| **밸류** / **밸류에이션** (valuation) | 「이 회사·주식을 **얼마로 평가할지**」. PER·PBR 등이 도구. |
| **멀티플** (multiple) | 배수 m. 「이익의 몇 배」「장부의 몇 배」. |
| **PER** (Price Earnings Ratio, 주가수익비율) | 주가 ÷ EPS = 시총 ÷ 순이익. **「지금 이익의 몇 배로 사나」**. 단위 **배**. |
| **PBR** (Price Book-value Ratio, 주가순자산비율) | 주가 ÷ BPS = 시총 ÷ 자본. **「장부가치의 몇 배로 사나」**. 단위 **배**. |
| **PSR** (Price Sales Ratio, 주가매출비율) | 시총 ÷ 매출(또는 주가÷주당매출). **「매출의 몇 배로 사나」**. 이익이 작을 때 참고. |
| **m_시장** | 지금 시장이 주는 배수 ≈ 화면의 PER. |
| **m_내기준** | 내가 「이 정도면 사겠다」고 정한 배수(예: 6~8). |
| **앵커** | 판단의 **기준점**. 예: 업종 평소 PER 12배를 앵커로 두고 ± 가감. |
| **가감** | 앵커에 더하거나 빼는 조정. |
| **할인** | 싸게 거래됨. 지금 가격 < 적정 → 할인(여유). |
| **할증** | 비싸게 거래됨. 지금 가격 > 적정 → 할증. |
| **안전마진** (margin of safety) | 적정가치보다 **얼마나 싸게 사는지**의 완충. |
| **천장** | 「이 이상 배수는 과하다」는 감각적 상한. 통화의 제조국 PBR ~7 등. |
| **상대 비교** | 「절대 싸다」가 아니라 **다른 종목보다 덜 비싸다**는 비교. |
| **절대 기준** | 내 m만으로 「싸다/비싸다」를 판정. |

**PER 예:** 주가 16,600원, EPS 1,000원 → PER = 16.6배.  
**PBR 예:** 주가 74,000원, BPS 10,000원 → PBR = 7.4배.

### 0-7. 배당

| 용어 | 풀이 |
|------|------|
| **배당** (dividend) | 회사가 이익 일부를 **주주에게 현금 등으로 나눠 주는 것**. |
| **DPS** / **주당 배당금** | 주식 1주당 배당액. 단위 원/주. |
| **배당수익률** | 주당 배당 ÷ 주가 × 100(%). 「이 주가에 사면 배당으로 연 몇 %」. |
| **배당주** | 배당을 꾸준히·의미 있게 주는 주식. |

**예:** 주당 배당 3,000원, 주가 172만 원 → 수익률 ≈ 0.17%(매우 낮음).

### 0-8. 투자 행동·시장 은어

| 용어 | 풀이 |
|------|------|
| **FOMO** (Fear Of Missing Out, 포모) | 「나만 소외될까 봐」 **급등한 뒤 추격 매수**하는 심리. 통화에서 경계. |
| **추격** | 이미 크게 오른 뒤 따라 사는 것. |
| **분할** (분할 매수/매도) | 한 번에 몰빵하지 않고 **여러 번에 나눠** 사고팔기. |
| **관망** | 당장 안 사고 **지켜봄**. |
| **비중** | 내 전체 자산 중 그 종목이 차지하는 비율. 비중 축소 = 일부 판다. |
| **포트** / **포트폴리오** (portfolio) | 내가 가진 투자 **묶음**. |
| **분산** (diversification) | 한 종류만 들지 않고 **역할을 나눠** 담기. |
| **가치주** | 상대적으로 **싸 보이는(저평가) 성격**의 주식으로 묶어 부르는 말. |
| **성장주** | 실적·스토리 **성장 기대**가 큰 주식으로 묶어 부르는 말. |
| **우상향** | 차트·실적이 **오른쪽 위로** 장기 상승하는 모습. |
| **고점** | 최근 구간의 **높은 가격대**. |
| **저점** / **바닥** | 최근 구간의 **낮은 가격대**. |
| **조정** | 급등 후 **가격이 되밀리는** 구간. |
| **수급** | 누가 사고파는지(외국인·기관·개인 등)의 **매매 흐름**. |
| **나스닥** (NASDAQ) | 미국 기술주 중심 시장·그 지수를 흔히 이르는 말. |
| **코스피** | 한국 대표 주식시장·지수. |
| **선물** | 미래의 가격으로 거래하는 파생상품. 통화에 「나스닥 선물」 등으로 등장. |
| **ADR** | 미국 밖에서 미국 증시에 상장된 해외주식 증서. 테슬라 원화 환산 화면과 달러 원본이 다를 수 있는 이유 중 하나. |
| **원화 환산** | 달러 등 외화 숫자를 **원화로 바꿔** 보여 줌. 환율에 따라 숫자가 움직임. |

### 0-9. 업종·나라·사이클

| 용어 | 풀이 |
|------|------|
| **반도체** | 전자기기 두뇌·기억 부품을 만드는 산업. 삼성전자·SK하이닉스 등. |
| **메모리** | 반도체 중 **저장**용(DRAM, NAND 등). 가격이 **호황·불황으로 크게 출렁**임. |
| **사이클** (경기·업황 사이클) | 실적·가격이 **올랐다 내려갔다** 반복되는 성질. 메모리 전형. |
| **호황** | 업황이 좋을 때(가격↑·이익↑). |
| **불황** | 업황이 나쁠 때. |
| **제조국** / **제조업** | 공장이 중심인 나라·산업. 통화: 배수를 낮게 주는 경향 언급. |
| **신흥국** / **이머징** (emerging) | 선진국 대비 시장이 덜 성숙한 나라로 묶어 부르는 말. 한국을 그렇게 분류해 할인(낮은 m) 이야기에 쓰이기도 함. |
| **월가** | 미국 금융·투자 업계를 상징적으로 부르는 말. |

### 0-12. 초보용 전체 그림 (30초)

1. 회사는 **이익(E)** 을 낸다.  
2. 사람들은 그 이익에 **배수(m)** 를 곱해 가격을 매긴다.  
3. **적정 ≈ E × m**.  
4. 지금 주가(또는 시총)가 그보다 낮으면 여유, 높으면 비쌈.  
5. **E를 키우면** 같은 주가도 싸 보이니, E는 신중히.  
6. **재무가 좋은 것**과 **가격이 싼 것**은 다르다(테슬라 예).

이제 아래 §1부터는 같은 내용을 **복습·예시**로 읽으면 됩니다. 본문에서도 용어 옆에 소괄호를 반복해 두었습니다.

## 1. 한 줄 핵심

**적정가치(이 정도면 적정하다고 보는 가격) ≈ 앞으로 벌 돈(E) × 내가 줄 배수(m)**

- 지금 **시총(시가총액·회사 전체 가격)** · **주가(주식 1주 가격)** 가 그보다 **작으면** 싸 보임
- **크면** 비싸 보임
- **배수(m, 멀티플)** 는 공식이 찍어주는 상수가 아니라 **내가 부여하는 판단**

### ▸ 부가 설명·예시 (1)

가게로 비유하면 쉽습니다.

- **E** = “이 가게가 1년에 순이익으로 남기는 돈”
- **m** = “그 이익에 몇 배를 쳐줘서 가게를 살까”
- **적정가치** = 그 둘을 곱한 값

**예시 A — 작은 가게**

- 1년 순이익 1억 원 (= E)
- “이런 가게는 보통 10배까지 쳐준다” (= m = 10)
- 적정 가치 = 1억 × 10 = **10억 원**
- 주인이 15억을 부르면 → 비싸다 / 8억이면 → 싸 보인다

**예시 B — 주식으로 옮기면**

- 회사 1년 순이익 50조 원, 내가 줄 배수 8배
- 적정 시총 = 50 × 8 = **400조 원**
- 지금 시총이 300조면 “여유”, 600조면 “비쌈”

**왜 “앞으로” 벌 돈인가**

주가는 어제 실적보다 **앞으로 벌 돈**을 미리 반영합니다.  
그래서 E는 가능하면 **내년(또는 향후 12개월) 이익**을 씁니다.  
다만 확신이 없으면 그 숫자를 깎아서 씁니다(§3).

**“싸다/비싸다”는 절대 가격이 아님**

주가 10만 원이라도 EPS가 1만 원이면 PER 10배이고,  
주가 100만 원이라도 EPS가 20만 원이면 PER 5배입니다.  
**가격 숫자만 보지 말고, 이익 대비 배수로 봅니다.**

## 2. 재무제표에서 보는 항목 (단위 포함)

**공시**(공개 자료)·**IR**(Investor Relations, 회사가 투자자에게 주는 설명 자료)은 억 원·백만 원이 섞여 나와도, 계산 전에 **조 원**으로 맞추면 편하다.  
(1조 원 = 1만 억 원)

| 이름 | 어디서 | 뜻 (쉬운 말) | 단위 |
|------|--------|----|------|
| **매출** (매출액) | **손익계산서**(얼마 팔고 남겼는지 보는 표) | 판 돈 (비용 빼기 전) | 조 원 / 1년 |
| **영업이익** | 손익계산서 | 본업으로 남긴 돈 | 조 원 / 1년 |
| **지배주주 당기순이익** | 손익계산서 | 주주 몫 최종 이익 → **E로 쓰기 좋음** | 조 원 / 1년 |
| **EPS** (Earnings Per Share, 주당순이익) | 주당으로 환산 | 주식 **1주당** 이익 | **원 / 주 · 년** |
| **자본(지배주주)** | **재무상태표**(자산·빚·자본을 찍은 표) | 장부상 주주 몫 | 조 원 |
| **BPS** (Book-value Per Share, 주당순자산) | 주당으로 환산 | 1주당 **장부**(회계장부) 가치 | **원 / 주** |
| **시가총액** (시총) | 시장 | 주가 × 주식 수 = 회사 전체 가격 | 조 원 |
| **주가** | 시장 | 주식 1주 거래 가격 | **원 / 주** |

- **영업이익률** (영업이익÷매출) = 본업 수익성 (%)
- **순이익률** (순이익÷매출) = 최종 수익성 (%)
- **PER** (Price Earnings Ratio, 주가수익비율) = 시총÷순이익 = 주가÷EPS → 「이익의 몇 배로 사나」, 단위 **배**
- **PBR** (Price Book-value Ratio, 주가순자산비율) = 시총÷자본 = 주가÷BPS → 「장부의 몇 배로 사나」, 단위 **배**
- (참고) **PSR** (Price Sales Ratio, 주가매출비율) = 시총÷매출 → 「매출의 몇 배로 사나」

매출·영업이익은 “회사가 얼마나 크고 본업이 얼마나 남나” **배경**.  
가격 판단의 본체는 **순이익(또는 EPS) × 배수**.

### ▸ 부가 설명·예시 (2)

#### 단위 맞추기 (자주 틀리는 부분)

IR 표에 `매출액 971,467 (억 원)` 이라고 나오면:

- 971,467억 원 ÷ 10,000 = **97.1467조 원**

| 표기 | 조 원으로 |
|------|-----------|
| 1,000억 원 | 0.1조 원 |
| 10,000억 원 | 1조 원 |
| 100,000억 원 | 10조 원 |

**잘못된 예:** 억 원 숫자와 조 원 숫자를 그대로 곱·나누기  
**올바른 예:** 둘 다 조 원(또는 둘 다 원)으로 맞춘 뒤 PER 계산

#### 손익이 위에서 아래로 흘러가는 그림

```
매출 (판 돈)
  − 원가·판관비 등
= 영업이익          ← “본업 실력”
  ± 금융손익·기타·세금
= 당기순이익
  → 그중 지배주주 몫   ← E로 쓰기 좋은 값
```

**예시 — 하이닉스 2025(대략)**

| 항목 | 금액 | 읽는 법 |
|------|------|---------|
| 매출 | 97.1조 원/년 | 규모가 큼 |
| 영업이익 | 47.2조 원/년 | 본업으로 매출의 약 절반을 남김 |
| 순이익 | 43.0조 원/년 | 세금 등 빼고도 많이 남김 → E 후보 |

영업이익률 ≈ 47.2 ÷ 97.1 ≈ **48.6%**  
→ “판 돈 100원 중 본업으로 약 49원” (메모리 호황기답게 매우 높음)

#### 시총과 주가, 둘 중 뭘 쓸까

- **회사 전체**로 생각: 시총(조 원) ÷ 순이익(조 원) = PER  
- **1주**로 생각: 주가(원) ÷ EPS(원) = PER  

둘은 같은 말의 다른 단위입니다.

**예시**

- 주가 172만 원, EPS 10.3521만 원  
- PER = 1,720,000 ÷ 103,521 ≈ **16.6배** (화면과 동일)

#### 매출·영업이익은 왜 “배경”인가

같은 순이익 10조라도

- 매출 20조에서 만든 10조(초고수익)와  
- 매출 200조에서 만든 10조(박리다매)

는 회사 성격이 다릅니다.  
그래서 매출·영업이익률로 **질**을 보고,  
**가격 태그**는 여전히 순이익(또는 EPS)×m으로 붙입니다.

#### PBR은 언제 보나

- PER: “지금·앞으로 벌 이익” 대비 비싸냐  
- PBR: “장부에 적힌 자본” 대비 비싸냐  

이익이 일시적으로 폭증·폭락하는 사이클 업종에서는  
PER만 보면 착시가 나서, PBR으로 “너무 과열인가”를 보조로 봅니다.  
(하이닉스 화면 PBR 7.4 ≈ 삼촌이 말한 제조국 천장~7 근처 → §8)

## 3. E (벌 돈) 잡는 법

1. **확정 숫자**: **연결**(모+자회사 합산) 손익의 **지배주주 당기순이익**(우리 주주 몫 최종 이익) (또는 **EPS**=주당순이익)
2. **앞을 본 숫자(더 중요)**: **가이던스**(회사 전망)·**컨센서스**(증권사 평균 전망) 내년 이익  
   — “언젠가”보다 **가까운 1년에 벌 것 같은 돈**
3. 확신이 없으면 그 숫자의 **70~100%만** 사용 (낙관 한 번 깎기)

통화 표현: “눈앞에 가져와” = 실현·거의 확실한 E(벌 돈)를 우선.

### ▸ 부가 설명·예시 (3)

#### 세 가지 E를 구분해서 적기

| 이름 | 뜻 | 예시 |
|------|----|------|
| **E_trailing** (트레일링=이미 나온 실적) | 이미 찍힌 최근 1년 이익 | 하이닉스 2025 순이익 ~43조 |
| **E_forward** (포워드=앞을 본 예상) | 앞으로 1년 예상 이익 | 컨센·가이던스 “내년 100조” |
| **E_내가쓸값** | forward에 신뢰도를 곱한 값 | 100조 × 0.8 = 80조 |

삼촌 말 “눈앞에 가져와” ≈ **E_내가쓸값**을 허황되지 않게 잡으라는 뜻.

#### 예시 — 같은 회사, E를 어떻게 잡느냐에 따라 결론이 바뀜

가정: 지금 시총 800조 원.

| E 선택 | 금액 | 지금 PER | 느낌 |
|--------|------|----------|------|
| trailing 40조 | 40조 | 800÷40 = **20배** | 비싸 보일 수 있음 |
| forward 100조 | 100조 | 800÷100 = **8배** | 싸 보일 수 있음 |
| 내가쓸값 80조 | 80조 | 800÷80 = **10배** | 중간 |

→ “포워드로 보면 싸다”는 말의 정체입니다.  
**E를 키우면 같은 주가도 싸 보입니다.** 그래서 E를 낙관으로만 키우면 자기합리화가 됩니다.

#### 신뢰도 깎기 예시

애널 평균이 “내년 순이익 120조”인데, 사이클·경쟁이 걱정되면:

- E_내가쓸값 = 120 × 0.75 = **90조**

그다음 m을 곱합니다.  
(여기서 m까지 공격적으로 올리면 이중 낙관 → §4 주의)

#### 일회성 이익은 빼기

예: 올해 순이익 50조 중 부동산 매각 차익 10조가 있다면  
지속 가능 E는 대략 **40조** 쪽으로 보는 식입니다.  
통화의 “매일 눈앞에 가져와”와도 맞닿아 있습니다.

#### 주당으로 할 때 (EPS)

시총 단위가 헷갈리면 **전부 1주 단위**로만 계산해도 됩니다.

- E = EPS (원/주)
- 적정주가 = EPS × m

하이닉스 화면: EPS 103,521원 × m …

## 4. m (배수) 잡는 법

“이 이익에 **몇 배까지 시총·주가를 인정해 줄까**”

1. **앵커**(기준점): 같은 업종·그 회사 과거 중간 **PER**(이익 대비 주가 배수)
2. **가감**(더하기/빼기)
   - 성장↑ → m 여유 / 성장↓·**사이클**(실적이 올랐다 내렸다 반복) → m 낮춤
   - 한국·제조·**신흥**(이머징·할인 받기 쉬운 분류) → m 낮춤 (통화: 대략 7 근처 **천장**=상한 감각도 언급)
   - 예측 쉽고 질 좋음 → m 여유
3. **상한**(이 이상 잘 안 줌): 애널·시장 천장보다 **한 단계 보수적으로**(빡세게) (예: 6~8배)

통화 감각 예:

| 상황 | m 감각 |
|------|--------|
| 보수·개인 | 대략 6~8배 |
| “10배면 잘 안 판다” | 매도 선을 높게 |
| 하이닉스 섹터 ~27배(당시) | 싸다 |
| 테슬라 ~300배 | 비싸다 → 안 삼 |

주의: E를 이미 낙관으로 올렸으면 m까지 올리지 말 것. **하나만 공격적으로.**

### ▸ 부가 설명·예시 (4)

#### m은 “점수”에 가깝다

시험으로 치면 E는 **점수(실적)**, m은 **가산점 배율**입니다.  
실적이 좋은데도 나라가·업종이 할인을 받으면 m을 낮게 줍니다.

#### 앵커 → 가감 → 상한 (따라 해보기)

**가상 예: 어떤 한국 제조 기업**

1. 업종 평소 PER 앵커 = **12배**
2. 가감
   - 실적 변동 큼(사이클) −3
   - 한국·제조 할인 −2
   - 근년 성장 강함 +2  
   → 가감 합 −3 → **9배**
3. 상한: “나는 보수적으로 최대 8배”  
   → **최종 m = 8배**

#### 통화의 “가이던스 × 계수”를 풀어서

삼촌이 말한 느낌(구술·대략):

- 포워드 성장·가이던스에 **나라/업종 계수 k**를 곱해 허용 배수 감각을 본다
- 신흥·제조는 k를 작게 (예: 7)

**개념 예시 (숫자 가정)**

- 어떤 성장 지표 g = 12  
- k = 7 (제조·신흥)  
- 허용 m 감각 ≈ 12 × 7 = **84배** (이건 “천장·비교용”에 가깝고, 개인 매수 배수 6~8과는 층위가 다름)

실무에서는:

- **매수 판단 m**: 6~8 (보수)
- **시장·비교 m**: 화면 PER, 업종 PER  
을 구분해 쓰는 편이 덜 헷갈립니다.

#### “10배면 못 판다 / 11배면 350”의 의미

- **매수 기준 m**과 **보유·매도 기준 m**을 다르게 둘 수 있음
- 싸게 사서(예: 6~7배 구간), 배수가 올라가도(10~11배) 바로 안 판다 = 여유를 둠
- 11배로 올려 보면 목표가가 확 올라감 (§9)

#### 테슬라 vs 하이닉스 — 같은 공식으로 비교 (통화 논리)

가정(통화 당시 감각):

| | 대략 m (PER) | 판단 |
|--|--------------|------|
| 하이닉스 | ~27배 | 상대적으로 싸다 |
| 테슬라 | ~300배 | 비싸다 |

“밸류만 보면 어디를 사겠냐” → **하이닉스**.  
재무가 좋아도 m이 극단이면 안 산다 = 테슬라 화면(PER 320)과 동일 논리.

#### 이중 낙관 금지 예시

| 잘못된 방법 | 결과 |
|-------------|------|
| E를 컨센보다 20% 올리고 + m도 8→15로 올림 | 목표가 폭등, 착시 |
| E만 보수적으로 깎고 m은 시장과 비슷 | 한쪽으로만 조정 → 권장에 가깝 |
| E는 forward 그대로, m만 6~8 | 삼촌식 보수에 가깝 |

## 5. 적정가치 읽는 법

**시총**  
예: 내년 100조 원 × 8배 → 적정 시총 감각 **800조 원**

**주가**  
예: EPS 2만 원 × 8배 → 적정 주가 **16만 원**

같은 시총이라도

- **작년 이익**으로 나누면 배수가 커 보이고
- **내년 이익**으로 나누면 배수가 작아 보인다  

→ “포워드·가이던스로 싸다”는 말의 요지.

### 실전 순서

1. 지배주주 순이익(또는 EPS) 확인  
2. 내년 이익 추정 (필요하면 깎기)  
3. 내가 줄 배수 정하기 (보수적으로)  
4. 곱해서 적정 시총·주가  
5. 지금 가격과 비교  
6. 보조로 PBR  
7. 오른 뒤 FOMO인지, 싸졌을 때 담는지 행동까지

### ▸ 부가 설명·예시 (5)

#### 워크스루 — 가상 종목 “A전자”

1. 작년 순이익 30조 → trailing  
2. 컨센 내년 45조, 나는 80%만 → E = 36조  
3. m = 8배 (보수)  
4. 적정 시총 V = 36 × 8 = **288조**  
5. 지금 시총 250조 → V보다 작음 → **여유**  
6. PBR이 업종 천장 근처면 “여유”를 조금 깎아 생각  
7. 최근 급등 후라 FOMO면 추격 안 함. 조정 시 분할

#### 주가 버전 워크스루

1. EPS_forward 내가쓸값 = 2만 원  
2. m = 8  
3. 적정주가 = 20,000 × 8 = **16만 원**  
4. 지금 12만 원 → 여유 / 지금 22만 원 → 비쌈

#### “목표가만 올리는” 두 가지 길

| 방법 | 식 | 예시 |
|------|-----|------|
| 이익이 늘어남 | EPS↑ × 같은 m | EPS 2만→3만, m=8 → 16만→24만 |
| 배수만 올라감 | 같은 EPS × m↑ | EPS 2만, m=8→12 → 16만→24만 |
| 둘 다 | 위험(이중 낙관) | 가능한 한 한쪽만 |

통화의 하이닉스 350만은 대체로 **둘 다 섞인 낙관 목표**에 가깝습니다(§9).

#### 여유율(안전마진)을 숫자로

적정 83만, 지금 172만이면:

- 지금 ÷ 적정 ≈ 172 ÷ 83 ≈ **2.1배 비싸게** 거래 중(그 가정 하에서)
- 반대로 적정 200만, 지금 160만이면 약 **20% 할인** → 여유

## 6. 통화에 나온 행동 규칙

| 할 것 | 하지 말 것 |
|--------|------------|
| 떨어지면 담기 (지수↓·**가치주**(상대적으로 싸 보이는 주식)↓ 각각) | 오른 뒤 **FOMO**(소외될까 봐 추격 매수) 추격 |
| 혼자 E, m 계산해 보기 | 종목 가볍게 물어보기 |
| **우상향**(장기 상승)+배당형도 **포트**(포트폴리오·보유 묶음)에 (예: 필립모리스) | **애널**(애널리스트) 숫자만 맹신 |

**고점**(높은 가격대) 매수: 연간 **가이던스**(회사 제시 전망)에 ~20% 성장이 보이면 고점도 감내 가능하다는 식의 언급도 있었음.

### ▸ 부가 설명·예시 (6)

#### FOMO를 \(E \times m\)으로 번역하면

주가가 급등했을 때:

- 화면 PER(m_시장)이 이미 내 기준 m보다 **훨씬 큼**
- 그런데 “더 오를 것 같아서” 사면 → **비싸다고 계산해 놓고도 추격**

통화: “떨어질 때 안 사고 오를 때 사지 마라 / 포모 보면 안 된다”

#### 하락 시 매수 규칙 (통화)

| 상황 | 행동 |
|------|------|
| 나스닥(성장·지수 쪽) 하락 | 그쪽을 담는다 |
| 가치주 하락 | 가치주를 한두 주 더 |

즉 “무조건 현금만”이 아니라, **싸진 바구니에 넣는다**는 뜻에 가깝습니다.  
전제: 그 바구니의 E×m이 여전히 납득될 때.

#### 고점 매수도 된다는 말의 조건

- “아무 고점”이 아님  
- **연간으로 성장이 눈에 보이는 가이던스(~20% 언급)** 가 있을 때  
- 고점이라도 m이 완전히 붕괴한 상태는 아닐 수 있음  

실무 번역: 고가라도 **forward PER이 내 상한 안**이면 분할 가능하다는 식.

#### 종목을 가볍게 묻지 말라는 이유

E·m·사업·사이클을 **그날 깊게** 봐야 하는데,  
가볍게 물으면 상대도 대충 답하고 본인도 대충 사게 됨.  
통화: 종목 질문은 심도 있게만.

#### 필립모리스 유형이 의미하는 것

- 월·연봉이 우상향  
- 배당  
- “묶어도(포트에 담아도) 된다”  

하이닉스·삼전 같은 **사이클·고성장 반도체**와 **역할이 다른 카드**입니다.  
전부 하이닉스식으로만 채우지 말라는 포트 **분산**(역할을 나눠 담기) 감각.

### ▸ 부가 설명·예시 (7)

#### 화면 숫자로 직접 계산

**지금 시장이 쓰는 식**

- E = EPS 1,541원/주  
- m = PER 320.5배  
- 암시 주가 ≈ 1,541 × 320.5 ≈ **493,891원 ≈ 49.4만 원**

**삼촌식 보수**

| m | 적정주가 (원) | 지금(약 49만) 대비 |
|---|---------------|-------------------|
| 6 | 약 9,246 | 약 53배 비쌈 |
| 8 | 약 12,328 | 약 40배 비쌈 |
| 12 | 약 18,492 | 약 27배 비쌈 |
| 20 | 약 30,820 | 약 16배 비쌈 |
| 50 | 약 77,050 | 약 6배 비쌈 |
| 320.5 | 약 49.4만 | = 시장 |

→ “조금 비싸다”가 아니라, **보수 배수로는 설명이 안 되는 가격**입니다.

#### ROE 4.6% + PBR 14배의 의미

대략적으로 PBR ≈ PER × ROE 관계가 성립하는 경우가 많습니다.

- 320.5 × 0.046 ≈ **14.7** → 화면 PBR 14.0과 비슷한 층위

해석:

- 장부 대비 14배를 주는데  
- 그 장부가 벌어 주는 수익률(ROE)은 연 4.6%뿐  
→ **지금 실력으로는 비싸고, 미래 성장 기대를 선반영**한 상태

#### 재무 양호 vs 밸류 비쌈

| 축 | 테슬라 화면 | 결론에 미치는 영향 |
|----|-------------|-------------------|
| 부채·유동성·이자 | 좋음 | “망할까” 걱정은 상대적으로 작음 |
| PER·PSR·PBR | 매우 높음 | “싸게 사나”에서는 탈락 |
| 배당 | 없음 | 배당형 포트 카드 아님 |

삼촌 논리: **망하지 않는 것과 싸게 사는 것은 별개**.

#### “$100에 산다”를 E×m으로 읽기

달러 주가가 내려가면 (EPS가 비슷할 때) PER이 내려갑니다.  
목표 매수가 = “내가 납득하는 m에 가까워지는 가격”입니다.  
원화 화면만 보면 환율·**ADR**(해외주식이 미국 시장에 상장된 형태 등) 이슈가 있어, **달러 원본 PER**을 같이 보는 것이 좋습니다.

## 9. 통화 “350만” vs 화면 계산 — 왜 다른가

**같은 공식 \(E \times m\)인데 넣는 숫자·시점이 다름.**

### 통화 흐름 (대략)

1. 당시 주가 ≈ **140만 원**
2. 삼촌 가정 이익으로 보면 약 **6~6.5배**
3. “10배면 잘 안 판다. **11배** 주면?”
4. → “**350 가죠**” (말)

산수만 하면:

\[
140만 \times \frac{11}{6.5} \approx 237만\text{ 원}
\]

→ **350만은 정확한 역산이라기보다**, 이익 증가까지 섞은 **대략 목표**이거나 말이 커진 쪽.  
(전사 오인식 가능성도 약간 있음.)

같은 통화의 다른 축: 이익 **100조 × 8배 → 시총 800조** 감각.  
이것과 “주가 350만”이 한 줄로 딱 맞지는 않음 (구술·가정 느슨).

### 비교표

| | 통화 (그때) | 화면으로 한 계산 |
|--|-------------|------------------|
| 주가 | ~140만 | ~172만 |
| E | “100조” 등 **앞을 본 가정** | EPS **10.3만 원**(화면) |
| m | 6.5 → **11** | 보수 **6~8** |
| 결과 | **350만(말)** / 산수 ~237만 | **62~83만**(8배) |

### 350만을 같은 식으로 맞추려면

- 화면 EPS(10.3만) 고정 → 350만 ÷ 10.3만 ≈ **PER 34배** 필요 (지금 16.6보다 큼)
- 배수 11배 고정 → 350만 ÷ 11 ≈ **EPS 약 32만 원** 필요 (화면의 약 3배)

**한 줄:**  
통화 350만 = 이익↑ + 배수↑의 **낙관 목표**.  
화면 62~83만 = 오늘 EPS + 보수 배수의 **아래쪽 기준가**.

### ▸ 부가 설명·예시 (9)

#### 세 시나리오를 표로 (하이닉스)

| 시나리오 | E (EPS) | m | 적정주가 | 성격 |
|----------|---------|---|----------|------|
| A. 화면+보수 | 10.3만 | 8 | **~83만** | 아래쪽 기준가 |
| B. 통화 산수(배수만) | (당시 6.5배에 대응) | 11 | **~237만** (140→11/6.5) | 배수 확장만 |
| C. 통화 말 | 더 큰 forward | ~11+α | **~350만** | 이익+배수 낙관 |

A와 C가 달라 보이는 것은 버그가 아니라 **가정이 다름**입니다.

#### “100조 × 8 = 800조”를 주가로 옮기는 연습

시총과 주가를 연결하려면 주식 수가 필요합니다.  
(대략 이해용; 정확한 희석·우선주 등은 공시 확인)

예: 주식 수 ≈ 7.28억 주라고 가정하면

- 시총 800조 원 = 800 × 10^12 원  
- 주가 = 800e12 / 7.28e8 ≈ **약 110만 원**

즉 통화의 “100조×8배”만 딱 적용하면 **350만이 아니라 100만 원대**에 더 가깝습니다.  
→ 350만은 **그 식과 별도로**, 더 큰 E나 더 큰 m을 섞은 목표로 보는 편이 맞습니다.

#### 타임라인으로 정리

```
[통화 시점]
  주가 ~140만, 삼촌 감각 PER ~6.5
  → 11배면 산수상 ~237만 / 말로는 350만

[화면 시점]
  주가 ~172만, PER 16.6, EPS 10.3만
  → 이미 “6.5배” 구간은 지나감
  → 보수 8배 기준 적정 ~83만 → 현재는 할증
  → 350만은 아직 “추가 이익 성장”이 필요한 목표
```

#### 실무에서 카드를 나누어 적기

메모장에 이렇게 쓰면 안 헷갈립니다.

```
기준가(보수): EPS_화면 × 8 = ___
보유상한: EPS_내가정 × 10~11 = ___
낙관목표: EPS_낙관 × 11 = ___   ← 여기가 350만 급
현재가: ___
현재 PER: ___
```

세 줄을 한 숫자로 섞지 않기.

- 통화: 보수 목표가 감각 **약 60만 원**(메모리 추가 상승 가정)

시세·컨센·화면 EPS는 시점에 따라 달라지므로, **판단할 때마다 E·m을 다시 넣을 것.**

### ▸ 부가 설명·예시 (10)

#### 하이닉스 2025 → 화면 EPS와의 관계

- 연간 순이익 ~43조, EPS가 어떤 앱에서는 ~5.9만 원대(결산)로도 나옴  
- 화면 EPS **10.3만**은 최근 급증 분기를 반영한 **TTM**(Trailing Twelve Months, 최근 12개월 합산)·다른 기준일 수 있음  

**포인트:** 앱마다 EPS 정의(결산/TTM/포워드)가 다릅니다.  
\(E \times m\)을 할 때는 **그 EPS가 어떤 기간인지**를 먼저 확인하세요.

#### 삼성 “60만” 역산 연습 (통화)

통화: 메모리 가격이 이미 크게 오른 뒤에도 추가 2~3배 여지 → 보수적으로 삼성 **~60만**.

주가 = EPS × m 형태라면, 예를 들어:

| 가정 EPS | 가정 m | 주가 |
|----------|--------|------|
| 3만 원 | 20배 | 60만 |
| 4만 원 | 15배 | 60만 |
| 5만 원 | 12배 | 60만 |
| 6만 원 | 10배 | 60만 |
| 7,500원 | 8배 | 6만 ← 2025 EPS만으로는 60만이 안 나옴 |

2025 EPS ~6,605원 × 8배 ≈ **5.3만 원**뿐.  
→ 삼촌의 60만은 **“지금 결산 EPS×8”이 아니라**,  
**앞으로 EPS가 훨씬 커진다는 경로**를 넣은 목표입니다.  
(하이닉스 350만과 같은 종류의 낙관·경로 가정)

#### 삼성과 하이닉스를 같은 틀로

| | 삼성(통화) | 하이닉스(통화/화면) |
|--|------------|---------------------|
| 보수 기준가 | (낮은 EPS×낮은 m) | 화면 EPS×6~8 → 62~83만 |
| 경로 포함 목표 | ~60만 | ~237만(산수)~350만(말) |
| 핵심 변수 | 메모리 가격·EPS 경로 | 메모리·EPS 경로 + 배수 확장 |

## 11. 복습용 초간단 체크

1. E = 내년 순이익 또는 EPS (단위: 조 원/년 또는 원/주)  
2. m = 내가 줄 PER (보수면 6~8 등)  
3. 적정 = E × m  
4. 지금 가격과 비교  
5. E와 m을 **동시에** 낙관하지 않기  
6. **FOMO**(소외될까 봐 급등 추격)로 추격하지 않기
