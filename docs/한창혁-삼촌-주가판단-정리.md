# 한창혁 삼촌 통화 — 주가 판단 정리

- 출처: 카카오톡 음성 `한창혁 삼촌_260731_1925.m4a` (약 14분) + 이후 테슬라·하이닉스 투자지표 화면
- 목적: 서버/코드와 무관. \(E \times m\) 방식으로 이해·복습용
- 작성: 2026-08-02

---

## 1. 한 줄 핵심

**적정가치 ≈ 앞으로 벌 돈(E) × 내가 줄 배수(m)**

- 지금 시총·주가가 그보다 **작으면** 싸 보임
- **크면** 비싸 보임
- 배수는 공식이 찍어주는 상수가 아니라 **내가 부여하는 판단**

---

## 2. 재무제표에서 보는 항목 (단위 포함)

공시·IR은 억 원·백만 원이 섞여 나와도, 계산 전에 **조 원**으로 맞추면 편하다.  
(1조 원 = 1만 억 원)

| 이름 | 어디서 | 뜻 | 단위 |
|------|--------|----|------|
| 매출 | 손익계산서 | 판 돈 | 조 원 / 1년 |
| 영업이익 | 손익계산서 | 본업으로 남긴 돈 | 조 원 / 1년 |
| 지배주주 당기순이익 | 손익계산서 | 주주 몫 최종 이익 → **E로 쓰기 좋음** | 조 원 / 1년 |
| EPS | 주당순이익 | 주식 1주당 이익 | **원 / 주 · 년** |
| 자본(지배주주) | 재무상태표 | 장부상 주주 몫 | 조 원 |
| BPS | 주당순자산 | 1주당 장부가치 | **원 / 주** |
| 시가총액 | 시장 | 주가 × 주식 수 | 조 원 |
| 주가 | 시장 | 거래 가격 | **원 / 주** |

- **영업이익률** = 영업이익 ÷ 매출 (%)
- **순이익률** = 순이익 ÷ 매출 (%)
- **PER** = 시총 ÷ 순이익 = 주가 ÷ EPS → 단위 **배**
- **PBR** = 시총 ÷ 자본 = 주가 ÷ BPS → 단위 **배**

매출·영업이익은 “회사가 얼마나 크고 본업이 얼마나 남나” **배경**.  
가격 판단의 본체는 **순이익(또는 EPS) × 배수**.

---

## 3. E (벌 돈) 잡는 법

1. **확정 숫자**: 연결 손익의 지배주주 당기순이익 (또는 EPS)
2. **앞을 본 숫자(더 중요)**: 가이던스·컨센서스 내년 이익  
   — “언젠가”보다 **가까운 1년에 벌 것 같은 돈**
3. 확신이 없으면 그 숫자의 **70~100%만** 사용 (낙관 한 번 깎기)

통화 표현: “눈앞에 가져와” = 실현·거의 확실한 E를 우선.

---

## 4. m (배수) 잡는 법

“이 이익에 **몇 배까지 시총·주가를 인정해 줄까**”

1. **앵커**: 같은 업종·그 회사 과거 중간 PER
2. **가감**
   - 성장↑ → m 여유 / 성장↓·사이클 → m 낮춤
   - 한국·제조·신흥 → m 낮춤 (통화: 대략 7 근처 천장 감각도 언급)
   - 예측 쉽고 질 좋음 → m 여유
3. **상한**: 애널·시장 천장보다 **한 단계 보수적으로** (예: 6~8배)

통화 감각 예:

| 상황 | m 감각 |
|------|--------|
| 보수·개인 | 대략 6~8배 |
| “10배면 잘 안 판다” | 매도 선을 높게 |
| 하이닉스 섹터 ~27배(당시) | 싸다 |
| 테슬라 ~300배 | 비싸다 → 안 삼 |

주의: E를 이미 낙관으로 올렸으면 m까지 올리지 말 것. **하나만 공격적으로.**

---

## 5. 적정가치 읽는 법

**시총**  
예: 내년 100조 원 × 8배 → 적정 시총 감각 **800조 원**

**주가**  
예: EPS 2만 원 × 8배 → 적정 주가 **16만 원**

같은 시총이라도

- **작년 이익**으로 나누면 배수가 커 보이고
- **내년 이익**으로 나누면 배수가 작아 보인다  

→ “포워드·가이던스로 싸다”는 말의 요지.

### 실전 순서

1. 지배주주 순이익(또는 EPS) 확인  
2. 내년 이익 추정 (필요하면 깎기)  
3. 내가 줄 배수 정하기 (보수적으로)  
4. 곱해서 적정 시총·주가  
5. 지금 가격과 비교  
6. 보조로 PBR  
7. 오른 뒤 FOMO인지, 싸졌을 때 담는지 행동까지

## 6. 통화에 나온 행동 규칙

| 할 것 | 하지 말 것 |
|--------|------------|
| 떨어지면 담기 (지수↓·가치주↓ 각각) | 오른 뒤 FOMO 추격 |
| 혼자 E, m 계산해 보기 | 종목 가볍게 물어보기 |
| 우상향+배당형도 포트에 (예: 필립모리스) | 애널 숫자만 맹신 |

고점 매수: 연간 가이던스에 ~20% 성장이 보이면 고점도 감내 가능하다는 식의 언급도 있었음.

| 항목 | 값 | 해석 |

| PER | 320.5배 | 이익 대비 매우 비쌈 |
| PSR | 11.8배 | 매출 대비도 비쌈 |
| PBR | 14.0배 | 장부 대비 비쌈 |
| EPS | 1,541원/주 | E(주당) |
| BPS | 31,689원/주 | |
| ROE | 4.6% | 자본 대비 이익 낮음 |
| 배당 | 없음 | |
| 부채비율 | 10.76% | 재무는 양호 |
| 유동비율 | 194% | 양호 |
| 이자보상 | 491% | 양호 |

대략 지금 주가 감각: 1,541원 × 320.5배 ≈ **49만 원대/주**(원화 환산)

**정리:** 재무는 괜찮은데, **E는 작은데 m만 극단적**이라 삼촌 기준으로는 비쌈.  
통화: 테슬라 대신 하이닉스, 테슬라는 싸질 때(예: $100 근처)까지 안 산다.

### 화면 EPS × 배수 → 적정주가

| 내가 줄 m | 적정주가 감각 | 172만과 비교 |
|-----------|---------------|--------------|

ROE 61%는 테슬라(4.6%)와 달리 **지금 벌어 주는 실력**이 큼.

## 9. 통화 “350만” vs 화면 계산 — 왜 다른가

**같은 공식 \(E \times m\)인데 넣는 숫자·시점이 다름.**

### 통화 흐름 (대략)

1. 당시 주가 ≈ **140만 원**
2. 삼촌 가정 이익으로 보면 약 **6~6.5배**
3. “10배면 잘 안 판다. **11배** 주면?”
4. → “**350 가죠**” (말)

산수만 하면:

\[
140만 \times \frac{11}{6.5} \approx 237만\text{ 원}
\]

→ **350만은 정확한 역산이라기보다**, 이익 증가까지 섞은 **대략 목표**이거나 말이 커진 쪽.  
(전사 오인식 가능성도 약간 있음.)

같은 통화의 다른 축: 이익 **100조 × 8배 → 시총 800조** 감각.  
이것과 “주가 350만”이 한 줄로 딱 맞지는 않음 (구술·가정 느슨).

### 비교표

| | 통화 (그때) | 화면으로 한 계산 |
|--|-------------|------------------|
| 주가 | ~140만 | ~172만 |
| E | “100조” 등 **앞을 본 가정** | EPS **10.3만 원**(화면) |
| m | 6.5 → **11** | 보수 **6~8** |
| 결과 | **350만(말)** / 산수 ~237만 | **62~83만**(8배) |

### 350만을 같은 식으로 맞추려면

- 화면 EPS(10.3만) 고정 → 350만 ÷ 10.3만 ≈ **PER 34배** 필요 (지금 16.6보다 큼)
- 배수 11배 고정 → 350만 ÷ 11 ≈ **EPS 약 32만 원** 필요 (화면의 약 3배)

**한 줄:**  
통화 350만 = 이익↑ + 배수↑의 **낙관 목표**.  
화면 62~83만 = 오늘 EPS + 보수 배수의 **아래쪽 기준가**.

## 11. 복습용 초간단 체크

1. E = 내년 순이익 또는 EPS (단위: 조 원/년 또는 원/주)  
2. m = 내가 줄 PER (보수면 6~8 등)  
3. 적정 = E × m  
4. 지금 가격과 비교  
5. E와 m을 **동시에** 낙관하지 않기  
6. FOMO로 추격하지 않기
