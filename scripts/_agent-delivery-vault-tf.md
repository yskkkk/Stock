# YSTOCK — intraday 설명 및 보관함 UI·알림 개선

## intraday(장중 재검증)란?

**Intraday**는 “장중에 보관함에 이미 들어 있는 **일봉 정배열** 종목만” 빠르게 다시 확인하는 기능입니다.

| 구분 | 내용 |
|------|------|
| 대상 | 보관함에 있는 **일봉(1d) 정배열** 종목만 |
| 시점 | 장중(폴링 약 1분 주기) |
| 하는 일 | MA5>20>60>120 정배열이 **유지되는지** 재확인 |
| 이탈 시 | 정배열이 깨지면 보관함에서 **제거** |
| 하지 않는 일 | 전체 유니버스 재스캔, 골든크로스 탐색, **주봉** 스캔 |

즉, 장 마감 후 돌리는 **일봉·주봉 전체 탐색**과는 별개로, 장중에는 “이미 걸려 있는 일봉 정배열”만 가볍게 갱신합니다. 코드: `server/ma-align-vault-intraday.js`, 폴러 `runVaultIntradayRescanIfDue`.

## 이번에 반영한 내용

### 1. 일봉·주봉 색 구분 (종목보관 UI)

- **일봉**: 파란 계열 — 카드 왼쪽 띠, 배지, 골든크로스 칩, 필터 탭
- **주봉**: 주황/앰버 계열 — 동일 요소에 적용
- 필터 탭(일봉/주봉) 활성 탭도 각 색으로 표시

### 2. 알림 — 일봉·주봉 교집합

동일 종목이 **일봉과 주봉 모두** 골든크로스 또는 정배열에 걸린 경우:

- **이메일**: 상단 `[일봉·주봉 교집합]` 섹션 (골든은 일봉/주봉 교차 각각 표기)
- **텔레그램**: 시장별 교집합 메시지 추가 발송
- 제목에 교집합 건수 포함

### 3. 모바일 말풍선(종목 카드)

- 좌측 고정(`translate(-100%)`) 때문에 화면 밖으로 나가던 문제 수정
- 좌/우 공간 부족 시 **아래·위** 중앙 정렬로 전환
- 실제 말풍선 크기 측정 후 뷰포트 안에 맞게 재배치
