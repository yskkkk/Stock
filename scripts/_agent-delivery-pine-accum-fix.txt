매집봉 통합 지표 미표시 — 원인·수정

원인 (가능성 높은 순)
1. 민감도가 지표마다 따로 있음
   - 2·상투·바닥 «민감도» ≠ 3·매집봉 «매집 민감도»
   - 2번만 느슨으로 바꾸면 매집은 기본 보통( RVOL 1.8 ) 그대로 → 신호 적음
2. 매집 계산이 request.security(주봉) 뒤에 있어 ta.sma(volume) 경로가 겹칠 수 있음

수정
- 매집 블록을 세력·security 호출보다 앞으로 이동
- 거래량 MA를 math.sum 방식으로 분리
- 3·매집봉 «매집 민감도» 기본값 느슨, 툴팁에 단독과 동일·2번과 별개 명시
- 느슨 시 최소 점수 45까지 완화 (단독 스크립트도 동일 적용)
- 매집 전용 «매집 탐지» «확정봉만» 입력 추가 (2·상투·바닥과 분리)

확인 방법
설정 → 3·매집봉 — 민감도·거래량 → «매집 민감도» = 느슨
표시 → «매집 탐지» «매집 ▲ 마커» ON
데이터 창 «매집 신호» 1인데 마커 없으면 표시 체크, 0이면 민감도·점수 조정
