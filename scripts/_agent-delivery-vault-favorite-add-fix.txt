종목보관 북마크 — 즐겨찾기 저장 안 됨 수정

원인
1. overlayVaultFavoriteState가 favoriteMeta에 없는 항목 favorited를 강제로 false 처리
2. 탭 prefetch(1.2s) applyVaultResponse가 stale favoriteMeta로 방금 추가한 즐겨찾기 덮어씀
3. patchVaultItemFavorite가 meta 없으면 favorited=true도 false로 저장

수정
- overlay: favoriteMeta 있는 종목만 favorited 보강 (해제는 patch로만)
- prefetch apply 시 skipFavorites — items·시세만 갱신
- 북마크 클릭 즉시 optimistic favoriteMeta + 스냅샷 반영, API 실패 시 롤백
- patchVaultItemFavorite: meta 없어도 favorited=true 가능
