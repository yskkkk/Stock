# YSTOCK — 업종 대장주 기준 개선

## 변경 전 (문제)

보관함에 **이미 들어 있는 종목끼리** 같은 업종 내 시총 1위만 대장주로 표시했습니다.

## 변경 후 (기준)

**국내 시총 상위 300 + 미국 S&P500** 전체 유니버스에서, 한글 업종명 기준으로 국내·미국을 **합산**해 판정합니다. 시총은 국내(KRW)→USD 환산 후 비교합니다.

### 대장주 충족 조건 (복합)

| # | 기준 | 설명 |
|---|------|------|
| 1 | **시총 1위** | 통합 업종 내 시가총액(USD 환산) 1위 |
| 2 | **시총 우위** | 2위 대비 시총 **1.3배 이상** (동률·근소 1위 제외) |
| 3 | **업종 규모** | 유니버스 내 동일 업종 **3종목 이상** |
| 4 | **수익성** | ROE 또는 이익률이 업종 중앙값 이상 (데이터 있을 때) |
| 5 | **성장성** | 매출성장률 업종 중앙값 이상 시 표시·가산 (미국 등 데이터 있는 경우) |

1~3 필수, 4는 재무 데이터가 있을 때 적용(국내 일부 종목은 데이터 부족 시 4번 면제), 5는 충족 시 상세에 표기.

## UI
