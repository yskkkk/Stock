버핏 + 실적 말풍선 동시 표시

요청
- «버핏» 클릭 시 가치투자(버핏) 말풍선은 그대로 두고, 실적/재무 요약 말풍선(호버 시 뜨는 것)도 함께 유지

변경
1. StockHoverBubbleActions — 버핏 클릭 시 onAfterAction(닫기) 호출 안 함. 차트·재무제표만 닫음
2. ValueInvestBubbleContext — 바깥 클릭 닫기 시 .earnings-icon-rail__bubble 안은 제외(실적 말풍선 조작 가능)
3. 실적 레일·보관함 — 버핏 말풍선이 같은 종목으로 열려 있으면 마우스가 벗어나도 실적 말풍선 유지

검증
- 실적 아이콘 호버 → «버핏» → 좌 실적 말풍선 + 우 버핏 말풍선 동시 표시
- 보관함 행 호버도 동일
