# 폴링 도크 UI 개선

## 변경 요약

1. **불투명 배경** — 폴링 팝오버·카드 배경을 반투명(color-mix)에서 불투명 solid로 변경. 글래스 라이트 테마에서도 차트가 비치지 않음.
2. **제목 아래 요약** — 각 카드 제목 밑에 `summaryKo`(설명 첫 문장) 표시.
3. **중지/시작 버튼 축소** — 카드 하단 우측 작은 버튼으로 배치(전체 너비 제거).
4. **카드 클릭 상세** — 카드 클릭 시 팝오버 하단에 상세 패널(전체 설명·주기·tick·env·오류) 표시. 같은 카드 재클릭 또는 × / Esc로 닫기.

## 확인 방법

앱 새로고침 → 우측 도크 **폴링** 아이콘 → 카드가 불투명한지, 요약 문구·작은 중지 버튼·카드 클릭 상세 패널 확인.
