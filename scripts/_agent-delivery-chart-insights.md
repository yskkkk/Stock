# YSTOCK — 종목보관 추세·이평 접근 + 로딩 개선

## 카드 표기 추가

### 일봉·주봉 추세
- **↑** MA5>20>60 상승 추세
- **↓** MA5<20<60 하락 추세
- **→** 그 외 횡보/중립

### 이평 근처 + 접근 방향
- 일봉·주봉 각각 MA20·60·120 이 2% 이내일 때 배지
- **하단접근**: 이평 아래에서 상승하며 접근
- **상단접근**: 이평 위에서 하락하며 접근
- 일봉=점선 배지 / 주봉=실선 배지

## 로딩 속도 개선

**원인**: `/api/stock-vault`가 모든 종목 주봉 차트를 기다리며 응답 지연

**조치**:
1. 메인 API는 **캐시된 chartInsights만 즉시 반환** (목록·시세 먼저 표시)
2. 차트 분석은 **백그라운드 갱신** (JSON 캐시 30분)
3. 클라이언트가 `/api/stock-vault/chart-insights`를 **탭 진입 후 비동기** 로드·90초 주기 갱신

→ 보관함 탭은 카드가 먼저 뜨고, 추세·이평 배지는 수 초 내 채워집니다.
