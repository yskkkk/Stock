# YSTOCK — 소식 탭 (국내 수급 순위)

## 기능

상단 **「소식」** 탭에서 국내 시총 상위 300종목(기존 골든크로스·정배열 스캔과 동일 유니버스)의 **외국인·기관·개인 순매수/순매도** 순위를 확인할 수 있습니다.

- 정렬 탭: 외국인 / 기관 / 개인 순매수 기준
- 컬럼: 종목, 외국인·기관·개인 순매수량, 외인보유율, 종가
- 종목 검색, 1분 클라이언트 폴링

## 서버

- 데이터: 네이버 `m.stock.naver.com/api/stock/{code}/trend`
- 폴러: **10분**마다 전체 스캔 (`STOCK_KR_INVESTOR_FLOW_POLL_MS`, 기본 600000)
- API: `GET /api/kr-investor-flow` (캐시 스냅샷), `?refresh=1` 수동 전체 스캔
- 저장: `kr-investor-flow-snapshot.json`

## 참고

- 장중·장마감 후 네이버 기준일(bizDate) 데이터가 반영됩니다.
- 첫 서버 기동 후 첫 스캔(약 2~4분)이 끝나야 표가 채워집니다.
