# 국내 수급 — 등락률·거래대금·보유 말풍선

## 변경
- 테이블 컬럼 추가: **등락률**, **거래대금** (네이버 trend 스캔 시 계산)
- 종목 행 클릭 → **투자자별 보유·수급 말풍선**
  - 상장주식수, 외국인 보유(%·주식수), 기관/개인 당일 순매수
  - 기관·개인 일별 보유율은 네이버 미제공 → 순매수로 표시(말풍선 하단 안내)

## API
- `GET /api/kr-investor-flow/:symbol/holdings` — 클릭 시 상장주식수·외국인 보유주식수 조회

## 확인
1. **국내 수급** 탭 → **새로고침** (등락률·거래대금은 재스캔 후 반영)
2. 종목 행 클릭 → 말풍선
