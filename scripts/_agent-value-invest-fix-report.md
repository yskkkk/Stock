# 10년 기대수익 말풍선 — 숫자 이상 원인·수정

## 원인

계산식 자체는 맞았고, **입력 성장률**이 비현실적이었습니다.

- 기존: `성장률 = Forward EPS ÷ Trailing EPS − 1`
- 삼성전자(005930.KS) 예: Trailing EPS 12,372원, Forward(컨센서스) 43,833원 → **약 +254%**
- 이 값을 **10년 매년 복리**에 그대로 넣어 EPS·주가·총수익이 기하급수적으로 커짐
- CAGR도 `(총수익/현재가)^(1/10)−1` 이라 **254% 근처**로 표시됨

Forward EPS는 **차기 1년** 컨센서스이지 10년 CAGR이 아닙니다.

## 수정

1. **성장률 산출** (`server/value-invest-growth.js`)
   - 우선: 연간 EPS 이력 CAGR (재무 아카이브)
   - 없으면: Yahoo revenueGrowth
   - 마지막: Forward÷Trailing (1년 추정)
   - **10년 복리 자동 상한 25%** — 초과 시 경고 문구 표시

2. **현재 주가**
   - 카드/수급 행의 **실시간 시세**를 API `?price=` 로 전달·기본 입력
   - 출처: "카드 실시간 시세"

3. **UI**
   - 참고(warnings) 목록
   - 각 결과 항목별 **계산 방식** (숫자 대입식)

## 계산식 (변경 없음)

| 항목 | 공식 |
|------|------|
| 10년차 EPS | 현재 EPS × (1+성장률)^년수 |
| 10년 총 EPS | 매년 EPS 합 (매년 ×(1+성장률)) |
| 10년 후 주가 | 10년차 EPS × PER |
| 10년 총 배당 | 10년 총 EPS × 배당 성향 |
| 총투자수익 | 10년 후 주가 + 10년 총 배당 |
| CAGR | (총투자수익 ÷ 현재 주가)^(1÷년수) − 1 |
| 적정가 | 총투자수익 ÷ (1+목표수익률)^년수 |

## 수정 후 스모크 (삼성전자, 주가 323,000원)

- 성장률: **25%** (이력 CAGR 75.5% → 10년 상한 적용)
- 적정가: **약 76만원** (기존 수십억 대비)
- CAGR: **약 25%**

직접 성장률을 253%로 넣으면 이전처럼 커집니다 — 말풍선에서 수동 조정 가능.
