## 1. 핵심 개념 요약

| 개념 | 내용 |
|------|------|
| 내재가치 | 미래 이익(EPS·현금흐름)을 **할인율**로 현재가치 합산한 값 |
| 할인율 | 최소 목표수익률(**허들 레이트**). 채권 수익률과 비교해 주식 매수 여부 판단 |
| 기회비용 | 다른 투자(예: CD 5%) 대비 포기하는 수익 → 주식은 더 높은 할인율/수익 요구 |
| 경영 위험 | 변동성이 아니라 **이익 예측 가능성**. 순환·예측 어려운 기업은 회피 |
| 안전마진 | 내재가치 산정이 주관적이므로, 보수적 가치 **이하**에서만 매수 |

## 2. 계산식 (책 예시)

### 2-1. 단순 5년 균일 이익 (표 9-3, 할인율 15%)

- 매년 이익 $10,000, 5년 합 $50,000
- PV = Σ 10,000 / (1.15)^t  (t=1..5) = **$33,522**

### 2-2. 채권 비교 (단순 적정가)

- EPS $2.50, 국채·회사채 수익률 6% → 적정가 ≈ **2.50 / 0.06 ≈ $41.7**
- 시장가 $50이면 수익률 5% → 채권 6%보다 불리

### 2-3. 맥도널드 예 (표 9-4)

- 10년 EPS 성장 **12%**, 이후 **5%**, 할인율 **10%**
- 10년 할인 EPS 합: **24.68**
- 잔여가치(continuation): **(7.76 / 0.05) / (1.10)^10 = 59.92**
- 주당 부채 차감: **-6.00**
- **내재가치 = 53.92** (주당)

일반식:
```
PV_10yr = Σ EPS_t / (1+r)^t
Terminal = (EPS_{n+1} / g_terminal) / (1+r)^n
Intrinsic = PV_10yr + Terminal - DebtPerShare
```

### 2-4. 버핏 할인율 관행 (책 서술)

- **10년 장기 국채 수익률**을 할인율로 사용 (단순·일관)
- 예측 가능한 이익 → 낮은 할인율(채권 수준), 순환·불확실 → 높은 할인율 또는 제외

## 3. Stock 앱 현황

- **재무(Financials)** 탭: 제무제표·AI 의견 등 — **DCF/내재가치 계산 없음**
- 종목 데이터: Yahoo `quoteSummary`, 국내 Naver 등 — EPS·부채 일부 확보 가능

## 4. 구현 시 제안 (원하시면 진행)

1. **재무 탭** 또는 **종목보관 행**에 “버핏식 내재가치” 패널
2. 입력: EPS 성장률(10년/이후), 할인율(기본=10년 국채), 주당부채
3. 출력: 10년 PV, 잔여가치, 내재가치, 현재가 대비 마진, 허들 대비 수익률
4. 데이터: Yahoo EPS·balanceSheet 자동 채움 + 사용자 수정
