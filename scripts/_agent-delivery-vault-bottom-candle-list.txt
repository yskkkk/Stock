종목보관 바닥캔들 20건 목록 안 보임

증상
- 바닥 캔들 배지 20인데 목록은 「보관된 종목이 없습니다」, 시장 필터도 전부 0

원인
1. 골든크로스(기본 선택) + 바닥캔들 동시 선택 → 교집합 0건인데 배지는 소스별 개수만 표시
2. items=[] 일 때 로컬 스냅샷만 쓰면 vault의 bottom_candle이 displayItems에 안 들어감
3. 즐겨찾기 필터 켜진 상태면 스캔 종목 0건으로 보임

수정
- vault prefetch 캐시 bottom_candle을 스냅샷과 즉시 병합
- 조건 추가 시 교집합 0이면 방금 누른 조건만 단독 선택 (중복 선택은 교집합 있을 때만)
- 탐색 조건 클릭 시 전체 필터로 전환 + 업종 all

확인: 바닥 캔들만 켜면 20건 목록 표시
