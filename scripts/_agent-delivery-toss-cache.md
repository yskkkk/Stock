# 토스 계좌 — 탭 전환 시 0 깜빡임 수정

## 문제
탭·도크 전환 시 토스 계좌 카드가 잠깐 0원/0%로 표시된 뒤 갱신됨.

## 조치
1. **계정별 클라이언트 캐시** (`localStorage` + 메모리) — 리마운트 직후 마지막 스냅샷 즉시 표시
2. **1초**: 서버 파일 캐시만 읽기 (`refresh=false`) — Toss API 미호출
3. **15초**: Toss Open API로 잔고·보유 갱신 후 파일 저장
4. **서버 폴러**: `live-trade-toss-ledger.json` 계정별 1초 터치 + 15초 API 백그라운드 갱신
5. **평가 손익**: `useTossSnapshotLiveQuotes`가 snapshot null일 때 이전 값 유지

## 커밋
`9948ff2`

## 확인
도크 계좌 탭 ↔ 다른 탭 전환 후 잔액·평가손익이 0으로 깜빡이지 않는지 확인.
