# 국내 수급 탭 — 투자자별 순위·업종

## 상단 탭
**국내 수급** (`investorFlow`) — 기존 "소식"에서 이름 변경

## 기능
- **투자자**: 외국인 / 기관 / 개인
- **순매수 상위** · **순매도 상위** (선택 투자자 기준 내림차순)
- **전체 목록** / **업종별** 그룹 보기
- **업종 필터** 칩, **업종별 수급 합계** 표 (클릭 시 필터)
- 종목 테이블에 **업종** 열 추가
- 새로고침 시 `?refresh=1` 전체 재스캔

## 서버
- 스캔 시 Naver 업종 조회 → `industry` 필드
- `industryTabs`, `industrySummary` 스냅샷 포함

## 확인
앱 새로고침 → **국내 수급** 탭 → 새로고침(첫 실행은 업종 조회로 1~2분 소요 가능)
