도크 «가동»(▶) 버튼 제거 — 판단·적용

판단
- 시작·중지·해제: 우측 도크 «실매매»(지폐) 레일 — 프로그램 카드 액션으로 동일
- 보유 요약(코인·수익률·평가·비중): 동일 레일 카드 펼침
- 목표매도·손절·체결 상세: 가동 중이면 실매매 메인 탭에 LiveSimRunningPanel 자동 표시(도크 사용 중에도 activeRunCount>0이면 인라인)
- 프로그램 목록·신규: 도크 «신규»·숨김 카드(프로그램)로 대체

결론: 도크 전용 «가동» 탭은 레일+실매매 탭으로 기능 대체 가능 → 레일 버튼 제거

변경
- activity 사이드탭 등록·도크 포털(LiveSimRunningPanel) 제거
- LIVE_TRADE_CARD_TAB_ORDER·railTabShort에서 activity 삭제

이후
- 도크에서 목표매도/손절까지 보려면 가동 중 실매매 탭으로 이동(또는 실매매 레일 요약)
