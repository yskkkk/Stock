세력 바닥·바람개비 캔들 Pine 스크립트 생성 완료

파일: scripts/pine-saeryeok-bottom-candle.pine
TradingView: Pine Editor → 붙여넣기 → 차트 추가

■ 감지 패턴
1. 바닥·전형 — ①음봉 → ②갭하락 변곡 → ③갭상승 양봉+거래량
2. 바닥·변주 — 무갭 / 갭상승변곡 / 하락양봉 / 갭하락양봉 연속
3. 바람개비 — ①→②변곡→③ 같은 방향 (추세 지속, 다음 캔들 확인)
4. 상투 — 바닥 반대 (①양 → ②갭상승 변곡 → ③갭하락 음+거래량)

■ 매매 구간 (바닥 신호 시 자동 표시)
- 손절선: ②번(변곡점) 저가
- 분할매수 박스: ②저가 ~ ③종가
- 책 기준: ③번 봉 14:30~15:15 분할매수, 주봉은 금요일 장마감 전

■ 권장 설정
- 타임프레임: 주봉(W) 우선 (책 기준), 일봉 보조
- 민감도: 보통 → 엄격(신호 적음) / 느슨(신호 많음)
- 하락 추세 선행: 켜두면 하락 후 바닥만 표시

■ 알림
- 바닥 캔들 / 전형 바닥 / 바람개비 / 상투 — alertcondition 등록 가능

■ 표시
- ▲ 바닥, ▲변주, ↓/↑개비(바람개비), ▼상투
- + 노란 십자 = ② 변곡점 형성 중 (③ 대기)
