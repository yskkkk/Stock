「10년 수익」539 vs 「버핏 DCF」249 — 왜 반대로 보이나 (MSFT)

■ 한 줄
539는 "15% 목표수익을 10년 받으려면 이만큼까지 사도 된다"는 매수 상한이고,
249는 "이익(EPS)만 할인해 오늘 가치를 잡은" 보수적 내재가치입니다.
질문이 다릅니다.

────────────────────────
1. 지금 화면(10년 수익 말풍선)이 말하는 것
────────────────────────

최고 매수가 539.04 USD
  = (10년 후 예상 주가 + 10년 총 배당) ÷ (1 + 목표수익률)^10
  = (2,079.01 + 101.71) ÷ 1.15^10
  ≈ 2,180.72 ÷ 4.05 ≈ 539

적정가 대비 -28.15%
  = (현재가 387.28 − 적정가 539.04) ÷ 539.04
  → 현재가가 "539까지는 사도 15% 목표 달성 가능"한 기준보다 28% 싸다
  → 그래서 "괜찮은 가격"처럼 보임

10년 CAGR +19%
  = 지금 387에 샀을 때, 위 가정(성장·PER·배당)대로면
    10년 뒤 총수익(주가+배당)의 연평균 수익률이 19%라는 뜻
  → 목표 15%보다 높으니 "지금가가 유리"하게 나옴

핵심 가정(말풍선 입력값):
  • 기준 EPS = 10년 평균 (버핏 패널의 Trailing 16.78과 다를 수 있음)
  • 성장률 = 화면에 +19% (버핏 패널 +11.87%와 다를 수 있음 — 직접 수정했거나 평균 EPS 기준 CAGR)
  • 10년 후 주가 = 10년차 EPS × 역사적 평균 PER  ← PER 배수를 곱함
  • 배당 = 10년 EPS 합 × 배당성향(21%) 포함
  • 목표수익률 15% — "얼마까지 비싸게 사도 되나"의 기준

────────────────────────
2. 버핏식 내재가치(249)가 말하는 것
────────────────────────

내재가치 249 USD
  = 앞으로 10년 EPS를 매년 +11.87% 성장시키고
    4.48%(10년 국채)로 할인한 PV만 합산
  • PER을 곱하지 않음 (주가 배수 가정 없음)
  • 10년 이후 잔여가치 생략 (할인율 < 잔여성장 5%)
  • Trailing EPS 16.78 사용 (10년 평균 아님)
  • 배당·목표수익률 개념 없음

→ "오늘 이 회사 이익 흐름만 보면 주당 얼마 정도 가치인가"에 가깝고,
   시장이 주는 PER 프리미엄·성장 기대는 거의 반영 안 함.

현재가 387 > 249 → "내재가치 대비 고평가"

────────────────────────
3. 왜 숫자가 이렇게 벌어지나
────────────────────────

| 구분           | 10년 수익(539)        | 버핏 DCF(249)        |
|----------------|------------------------|----------------------|
| 질문           | 15% 목표로 살 만한가?  | EPS만으로 오늘 가치? |
| EPS            | 10년 평균              | Trailing 최근        |
| 성장률         | 화면 ~19%              | CAGR ~11.87%         |
| 미래 가치      | 10년차 EPS × PER       | 할인 EPS 합만        |
| 배당           | 포함                   | 없음                 |
| 할인/목표      | 목표수익 15%           | 국채 4.48%           |
| 잔여(11년~)    | PER로 10년차에 반영    | 생략                 |

가장 큰 차이 2가지:
  ① PER — 10년 수익은 "10년 뒤 EPS × 평균 PER(수십 배)"로 2,079까지 키움
     버핏 DCF는 PER 없이 EPS 달러만 할인 → 훨씬 작음
  ② 목표 — 539는 "투자자 수익 목표(15%)" 기준 매수한도
     249는 "회사 이익의 현재가치" 기준

────────────────────────
4. 그래서 뭐가 맞나?
────────────────────────

둘 다 "정답"이 아니라 가정이 다른 계산기입니다.

• 10년 수익 539 → "성장·PER·배당이 과거처럼 유지되면, 387는 15% 목표치보다 싸다"
• 버핏 249 → "PER 프리미엄 빼고 이익만 보면, 387는 그 가치보다 비싸다"

MSFT처럼 PER이 높고 성장 기대가 큰 종목은
  PER을 쓰는 모델(539)은 매수 여유가 크고,
  PER 없는 DCF(249)는 보수적으로 고평가로 나오기 쉽습니다.

────────────────────────
5. 확인 팁
────────────────────────

말풍선에서 성장률·PER·목표수익률을 바꾸면 539도 크게 변합니다.
버핏 패널은 재무 탭 하단 — 입력(EPS·CAGR·국채)이 말풍선과 같은지 비교해 보세요.

둘 다 투자 권유가 아니며, 같은 MSFT라도 "무엇을 기준으로 싸다/비싸다 볼 것인가"가 다릅니다.
